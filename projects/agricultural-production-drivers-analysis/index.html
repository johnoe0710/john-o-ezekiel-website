Context & objective

The project investigates which environmental and operational factors are associated with farm output. It is an explanatory and exploratory analysis, not a validated predictive model, and it explicitly documents a correction to an earlier ratio-based interpretation.

Data context

The analysis covers 3,000 observations and six base variables: rainfall, soil quality, farm size, sunlight, fertilizer, and crop yield. The dataset was originally found on Kaggle, but the specific listing could not be relocated; the raw data is not redistributed. The units for crop yield and the measurement periods for rainfall and sunlight are assumed, not confirmed.

Analytical approach

Excel Tables support data checks and feature preparation, followed by PivotTable exploration and a five-factor ordinary least-squares regression using the Data Analysis ToolPak. The documented validation gate checks residuals against each predictor. No train/test split or out-of-sample validation was performed.

Farm size is the strongest reported association; soil quality, fertilizer, rainfall, and sunlight are described as more modest positive associations. The exceptionally high in-sample fit is flagged by the project as a reason to suspect synthetic rather than field-collected data.

Limitations & availability

The original dataset listing is unavailable and raw data is not redistributed. Units and measurement periods are unconfirmed. The model has no out-of-sample validation, and its in-sample fit is unusually high. Findings describe associations only and should not be interpreted as causal or predictive. The published repository currently contains documentation and screenshots but not the workbook or raw data.

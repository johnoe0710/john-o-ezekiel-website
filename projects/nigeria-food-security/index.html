Nigeria Food Security

An analytical portfolio project investigating Nigeria's agricultural production system. Earlier public-facing title: "Who Feeds Nigeria?"

Excel · Power Query · SQL · SQLite · Power BI Complete

Overview

A self-directed analytical investigation into Nigeria's agricultural production and food security landscape, built as an end-to-end demonstration of the analytical workflow: data sourcing through data auditing, cleaning, modelling, SQL analysis, and dashboard visualization.

Research Questions

  • What is each region's contribution to Nigeria's food security?
  • How does agricultural production vary by region?
  • Which crops perform strongest at a commodity level?
  • How has agricultural production changed over time?
  • What role does import dependency play in the food system?

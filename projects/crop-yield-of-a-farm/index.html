Context & objective

This project organises simulated farm and environmental features into a dashboard for comparing output and derived yield rates across farm-scale, soil-quality, and rainfall groups. It is an exploratory description of the generated records, not evidence about real farms.

Data context

The dataset contains 3,000 simulated records with rainfall, soil-quality index, farm size, sunlight, fertilizer, and crop-yield fields. It has no location, date, or crop-type field. The source description calls crop_yield tons per hectare, but the project treats it as total farm output and derives a per-hectare rate; that interpretation is an unverified assumption. This website does not host the dataset.

Analytical approach

Power Query loads and checks the records. Derived fields group farms by scale, soil tier, and rainfall zone; PivotTables and a dashboard compare totals and averages. A separate correlation check compares farm size with gross output.

Commercial-scale groups have greater total and per-farm output, while the smallholder group has the highest derived per-hectare rate. The project cautions that this ratio alone does not establish greater efficiency. These are simulated data patterns, not causal or field conclusions.

Limitations & availability

The records are synthetic, contain no geographic or time context, and the interpretation of crop_yield as total output is an assumption. The analysis is descriptive; group cut points are analyst-defined. The public project repository currently provides documentation and screenshots but does not include the workbook or dataset.

Context & objective

This project describes changes in Nigeria's national crop production, area harvested, and yield and compares them with a rainfall proxy. Its objective is to demonstrate a full data workflow while keeping the distinction between national agriculture statistics and partial climate coverage visible.

Data context

FAOSTAT provides national crop production, area harvested, and yield records for 2000–2024. NASA POWER precipitation is aggregated from a 143-cell grid over central Nigeria, so it is a regional proxy rather than country-wide rainfall. The source repository documents attribution and licenses; this website does not redistribute either dataset.

Analytical approach

The workflow uses Power Query to prepare sources, a Power BI model and DAX measures to report trends, and an independent Python calculation for the blended yield-rainfall correlation. The report compares national production trends with the narrower rainfall coverage and documents the mismatch in geographic scope.

Limitations & availability

Crop statistics are national, but rainfall represents only a central band of Nigeria and cannot be described as country-wide climate coverage. There is no state-level breakdown or trade/import analysis. The reported correlation is not causal and has no significance testing or controls. Data source and attribution detail is maintained in the project repository.

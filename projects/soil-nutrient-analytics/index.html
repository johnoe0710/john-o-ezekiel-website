Context & objective

The project examines nutrient and soil-condition records alongside a supplied fertilizer-name label. The goal is to describe the data and test whether the label is supported by the recorded soil variables, not to recommend fertilizer application.

Data context

The project uses 8,000 rows covering nitrogen, phosphorus, potassium, temperature, humidity, soil moisture, soil type, crop type, and fertilizer label. The repository identifies the Kaggle “Crop and Soil DataSet” and its listed MIT license, but the collection or generation method is not explained. The website does not host a copy of the data.

Analytical approach

Power Query cleans and derives fields for totals, potassium-zero flags, and a temperature-to-moisture ratio; DAX measures and PivotTables feed an interactive Excel dashboard. Separate Python checks reproduce statistics and test the fertilizer label against the soil variables.

For most of the file, the label prediction test is close to chance. The project concludes that fertilizer recommendations from this dataset are unsupported. Potassium recorded as zero is treated as a dataset flag, not a laboratory deficiency threshold.

Limitations & availability

The data source does not explain collection or generation. Nutrient units are unverified, there is no yield or crop-response outcome, and most fertilizer labels show no useful signal in this file. Do not use the dashboard to select or apply fertilizer. Source data remains in the separate project repository.

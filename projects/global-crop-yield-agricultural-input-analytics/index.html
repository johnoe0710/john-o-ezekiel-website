Context & objective

The report compares crop yield density across countries and crops over time and examines how it relates to climate and input measures. It is diagnostic and descriptive: it does not forecast yields or claim that observed associations are causal.

Data context

The model covers 101 countries, 10 crops, and 13,130 country-crop-year records from 1990–2013. Yield is recorded by crop and year, while pesticide and rainfall data are at country-year grain. The project's source and licensing notes are in its independent repository; no underlying dataset is copied to this website.

Analytical approach

Power Query prepares the inputs for a star schema with a yield fact table and crop, location, and date dimensions. Fifteen DAX measures support aggregation, ratios, gap-aware time comparisons, and correlation. The report is organised into Executive Overview, Agronomic & Input Impact, and Regional & Crop Deep-Dive pages.

Limitations & availability

The analysis is descriptive, not predictive; correlations do not establish cause. Measures must respect the different grains and intensive nature of the model fields. The project's linked data documentation is the authority for source and license details; this website hosts screenshots only, not source data or the PBIX.

Project repository

The public repository contains the project documentation, methodology, findings, and screenshots. The underlying raw dataset is excluded because its redistribution licence could not be independently confirmed.
